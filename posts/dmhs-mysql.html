测试捕获器组件

切换到dmhs的bin目录，执行ldd libcpt_mysql.so确保没有not found的库文件行输出

[root@localhost bin]# cd /opt/dmhs/bin
[root@localhost bin]# ldd libcpt_mysql.so | grep 'not found'

源端DMHS配置

尽量使用ip而不是用hostname(测试版本有此限制，以后或许会修复)

[root@localhost bin]# vim dmhs_src.xml
<?xml version="1.0" encoding="GB2312"?>
<dmhs>
    <base>
        <lang>en</lang>
        <mgr_port>5345</mgr_port>
        <ckpt_interval>45</ckpt_interval>
        <siteid>1</siteid>
        <version>2.0</version>
    </base>
    <cpt>
        <db_type>mysql</db_type>
        <db_server>127.0.0.1</db_server>
        <db_port>3306</db_port>
        <db_name>test</db_name>
        <db_user>test</db_user>
        <db_pwd>jiangc365</db_pwd>
        <ddl_mask>op:obj</ddl_mask>
        <arch>
            <clear_interval>600</clear_interval>
            <clear_flag>0</clear_flag>
            <dir>/data/mysql_src</dir>
        </arch>
        <send>
            <ip>192.168.16.134</ip>
            <mgr_port>6345</mgr_port>
            <data_port>6346</data_port>
        </send>
    </cpt>
</dmhs>

UnixODBC的安装

如果无法连接物联网，可以考虑使用操作系统的镜像文件进行提取安装

yum -y install unixODBC

MySQL的ODBC安装

建议使用dmhs搭建文档中推荐的ODBC版本

wget https://cdn.mysql.com/archives/mysql-connector-odbc-5.1/mysql-connector-odbc-5.1.13-1.el6.x86_64.rpm

rpm -ivh mysql-connector-odbc-5.1.13-1.el6.x86_64.rpm

ODBC连接配置

确定配置文件路径

使用odbcinst -j查看odbc配置文件路径：一般odbcinst.ini是驱动配置文件，odbc.ini是连接配置文件

[root@localhost bin]# odbcinst -j

unixODBC 2.3.1
DRIVERS............: /etc/odbcinst.ini
SYSTEM DATA SOURCES: /etc/odbc.ini
FILE DATA SOURCES..: /etc/ODBCDataSources
USER DATA SOURCES..: /root/.odbc.ini
SQLULEN Size.......: 8
SQLLEN Size........: 8
SQLSETPOSIROW Size.: 8

修改ODBC驱动配置文件

如果是通过rpm包安装的，通常不需要手动配置如下文件

[root@localhost bin]# cat /etc/odbcinst.ini

[MySQL]
Description=ODBC for MySQL
Driver=/usr/lib/libmyodbc5.so
Setup=/usr/lib/libodbcmyS.so
Driver64=/usr/lib64/libmyodbc5.so
Setup64=/usr/lib64/libodbcmyS.so
FileUsage=1

[MySQL ODBC 5.1 Driver]
Driver=/usr/lib64/libmyodbc5.so
UsageCount=1

修改ODBC连接配置文件

Driver可以指定odbcinst.ini中括号中的节点名，也可以在下方直接指定libmyodbc.so文件绝对路径

[root@localhost bin]# cat /etc/odbc.ini
[MySQL]
Driver=MySQL
DATABASE=mysql
Server=localhost
UID=root
PASSWORD=jiangc

测试ODBC连接配置

isql命令后接的参数为odbc.ini配置文件中括号里面的名称

启动同步

graph LR A[目的端:运行dmhs_server] --> B[目的端:启动执行器] B --> C[源端:运行dmhs_server] C --> D[源端:设置日志分析起点] D --> E[源端:初始化装载] E --> F[源端:启动捕获器]

目的端

1、运行dmhs_server

  • 使用上文中的dmhs_src.xml配置文件启动源端
[root@localhost bin]# cd /opt/dmhs/bin
[root@localhost bin]# ./dmhs_server dmhs_src.xml

2、启动执行器

  • 使用控制台连接到目的端管理服务
[root@localhost bin]# cd /opt/dmhs/bin
[root@localhost bin]# ./dmhs_console

DMHS> connect 127.0.0.1:5345
execute success
  • 启动执行器
DMHS> start exec
execute success

源端

1、运行dmhs_server

  • 使用上文中的dmhs_dst.xml配置文件启动源端
[root@localhost bin]# cd /opt/dmhs/bin
[root@localhost bin]# ./dmhs_server dmhs_dst.xml

2、设置日志分析起点

  • 使用控制台连接到目的端管理服务
[root@localhost bin]# cd /opt/dmhs/bin
[root@localhost bin]# ./dmhs_console

DMHS> connect 127.0.0.1:6345
execute success
  • 设置日志lsn起点
DMHS> set exec lsn
execute success

3、初始化装载

DMHS> copy 0 "SCH.NAME='test'" CREATE|INSERT|DICT

4、启动捕获器

DMHS> start
