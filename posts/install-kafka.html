快速安装 Kafka

日常运维

安装 Kafka 可以按照以下步骤进行，确保你已经安装了 Java（推荐使用 JDK 8 或更高版本）。

1. 下载 Kafka

访问 Apache Kafka 的官方网站 下载最新版本的 Kafka。选择你需要的版本，然后下载并解压缩。

例如，使用 wget 命令下载（以 2.8.0 为例）：

wget https://downloads.apache.org/kafka/2.8.0/kafka_2.12-2.8.0.tgz  
tar -xzf kafka_2.12-2.8.0.tgz  
cd kafka_2.12-2.8.0

2. 启动 ZooKeeper

Kafka 依赖 ZooKeeper，因此需要先启动 ZooKeeper。Kafka 自带一个简单的 ZooKeeper 实例，可以直接使用：

bin/zookeeper-server-start.sh config/zookeeper.properties

3. 启动 Kafka 服务器

在另一个终端窗口中，启动 Kafka 服务器：

    bin/kafka-server-start.sh config/server.properties

4. 创建一个主题

在 Kafka 启动后，你可以创建一个主题：

bin/kafka-topics.sh --create --topic test --bootstrap-server localhost:9092 --partitions 1 --replication-factor 1

5. 生产和消费消息

你可以使用以下命令来生产消息：

bin/kafka-console-producer.sh --topic test --bootstrap-server localhost:9092

在命令行中输入消息，然后按回车发送。

然后，在另一个窗口中消费消息：

bin/kafka-console-consumer.sh --topic test --from-beginning --bootstrap-server localhost:9092

6. 关闭服务

要停止 Kafka 和 ZooKeeper，可以使用 Ctrl+C 中断命令行中的进程。
