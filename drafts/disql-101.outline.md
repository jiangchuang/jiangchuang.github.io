## 二、骨架：工具类文章四问

这是给所有「我的小工具/我的做法」类文章定的默认结构。四问缺一问就会变成软文。

1. **疼在哪**（用读者自己的话，不用厂商语言）
   判据：这句话能不能被读者原样转发到群里说「对，就是这样」。
   反例：「提升数据库运维效率」——没人会这么说话。

2. **现成的为什么不行**（只写结构事实，不写优劣判断）
   判据：每条都要能指向一份公开文档或一次可复跑的操作。
   反例：「太重了」——重不重是个键盘感受，不是事实。

3. **我凭什么**（只写可验证的差异，一条一句）
   判据：读者能不能在五分钟内自己验证这一条。
   反例：「性能更好」——好多少，跟谁比，谁测的。

4. **它不适合谁**（必须写）
   判据：写完这一条，文章的攻击面才成立。缺了它，前三问就是推销。
   反例：不写。

**红线**：第三问里禁止出现「更好 / 更强 / 替代 / 吊打」，只允许写「我做了什么 + 你怎么验证」。

## 三、正文事实清单（已核，可直接引用）

### 疼点 1：方向键与退格在 disql 里不是编辑键

- 现象：按上箭头出现 `^[[A`，按退格出现 `^H` 或乱码，不能回翻历史、不能移动光标。
- 原因（不是 bug）：disql 未集成 GNU Readline，不具命令行历史与行内编辑能力；方向键的控制字符序列它不认识，于是原样打印。
  来源：达梦技术社区《DISQL 使用常见问题与解决》、同站《disql 在交互模式下无法使用上下左右键…的解决方案》。
- 官方给的解法：`rlwrap disql SYSDBA/密码@主机:5236`。

### 疼点 2：「每次都要 SET 一遍」——其实不用

- 真实情况：`SET PAGESIZE / LINESIZE / TIMING / LONG / SERVEROUTPUT` 这些每次开会话都要重设一遍，所以很多人把它们存成 `.sql`，用时复制粘贴。
- 反转：disql 连上库时会**自动执行** `$DM_HOME/bin/disql_conf/glogin.sql`，以及启动目录下的 `login.sql`。把 SET 写进 glogin.sql 就是一次配好、永久生效。
  来源：达梦官方文档《SQL 交互式查询工具》4.5「使用配置文件设置环境变量」。
- 文章价值：把「收藏一堆脚本」换成「配一个文件」。这是本篇的核心，也是最容易被忽略的一条。

### 疼点 3：「元命令太少」这个前提要改

- 事实：disql 的元命令有 17 个左右——`HELP / SET / SHOW / APPEND / ACCEPT / COLUMN / CONNECT / CLEAR / DESCRIBE / DEFINE / HOST / EDIT / EXIT / MORE / LIST / PROMPT / PRINT / QUIT / SPOOL / WHENEVER`。
- 所以不是「没有」，是**没人告诉你有哪些**，而 `help` 的输出是英文片语式，小白读不懂。
- 这条反差建议直接做文章的第二段：读者的抱怨是「缺功能」，真相是「缺发现」。

### 疼点 4：两个高频小坑

- 大字段只显示 800 字节：`SET LONG 20000`（`LONG` 默认 800）。
- 密码含 `@` 或 `/` 时连不上：要用引号包起来，如 `disql SYSDBA/'\"Test@xxx123\"'@localhost:5236`。

### 待实测（你有环境，我没有）

- 你提到的「输错要 Ctrl+←」：在你这台/这个终端里，具体是 `Ctrl+Backspace` 删词，还是方向键直接乱码？这条要按你的真实键盘写，我不替你猜。
- Windows 下 disql 的退格是否本来就正常（Windows 与 Linux 表现不同，别写成全平台都坏）。

## 四、第三问怎么写（dmkit 与 DEM 的结构差异，不写优劣）

可验证的差异，每条读者都能自己看一眼：

| | DEM | dmkit |
|---|---|---|
| 怎么拿到 | 官网写「拨打热线申请获取」 | 一个压缩包，解压即用 |
| 依赖 | Tomcat + JAVA 1.8；被监控机要装 dmagent | 单文件，零运行时 |
| 资源 | 官方建议 2G 以上内存；后台库存储建议不小于 100GB | 跑完即退，不常驻、不占端口 |
| 额外改动 | dmagent 与被监控机要做时间同步（建议 ntp） | 被试库不做任何改动 |
| 常驻形态 | 长期在线的监控平台 | 现场一次性取证 |

**必须紧接着写的那句**：这不是替代关系。要长期盯十台库、要告警和审计留痕，DEM 是对的；只有一台库、现在就要看清楚，装一套平台的时间已经超过排查本身。

**不写的话**：「DEM 以后可能要收费」——这是对厂商商业策略的猜测，不是事实。写进去就把文章的立场从「我做了个东西」变成「我在带节奏」，而读者一眼能看出来。可写的只有官网现状：**它现在需要申请获取**。
