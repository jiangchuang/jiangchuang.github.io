## 关于

这里是我在达梦数据库（DM8）一线交付与运维中整理下来的实践记录。

第一期聚焦 **故障恢复** 这一类现场最高频的问题，每篇都有两个版本：

- **交互版**（`interactive/`）：视频实录 + 分步卡片 + 命令一键复制，现场照着敲最顺手
- **图文版**（`posts/`）：与交互版逐条对应，命令与输出均为实测，可被搜索引擎收录

选题尽量做到 **具体报错原文 + 具体版本 + 具体场景**，方便遇到同样问题的人按关键词搜到。

## 站点结构

```
index.html            首页（交互指南 + 对应图文版两个板块）
search.html           站内搜索页
interactive/*.html    交互式操作指南（视频内嵌 + 分步卡片）
interactive/*.mp4     指南内嵌的操作录屏
posts/*.html          与交互版逐条对应的图文版
assets/site.css       全站样式（两套主题的变量都在这一个文件里）
assets/search.json    搜索索引（收录全部 10 篇）
assets/video/         图文版内嵌的录屏
.nojekyll             关闭 Jekyll，纯静态直出
projects/*/           站外小项目源码（不随站点发布，各自有 README）
```

纯静态站点：**无后端、无构建步骤**，克隆下来直接打开 `index.html` 就能看。

`projects/` 下放的是独立小项目的源码，与站点内容无关，不会被部署到线上；目前有 `projects/budget/`（家庭装修预算协同账本）。

## 主题

内置两套配色，导航栏右上角按钮切换，选择记在浏览器本地：

| 主题 | 风格 |
|---|---|
| `ink`（默认） | 水墨 —— 宣纸底 + 朱砂 + 衬线标题 |
| `dark` | 墨夜 —— 深色底 + 青色 + 无衬线 |

想加第三套：复制 `assets/site.css` 里 `html[data-theme="dark"]{ ... }` 那一块，
改个名字和颜色值即可 —— 组件样式全部走 CSS 变量，不用碰。
